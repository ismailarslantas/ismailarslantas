### 🦁 Lionstone — open-source AI video editing agent

I spent two decades cutting podcasts, interviews and talks by hand. **[Lionstone](https://github.com/ismailarslantas/lionstone)** turns that craft into an agent:

- **Speech-aware cuts** — removes silences, fillers and false starts without chopping words
- **Captions, titles & loudness** — broadcast-ready audio, readable subtitles, cinematic title effects (Remotion)
- **QA before delivery** — catches black or frozen frames, loudness peaks, clicks at joins and clipped words
- **Works with Claude** — ships an MCP server, so you can edit a video by talking to your assistant

```bash
pip install "lionstone[whisper] @ git+https://github.com/ismailarslantas/lionstone"
lionstone edit talk.mp4
```

<sub>FFmpeg · Whisper · Remotion · MCP · Python · TypeScript — Apache-2.0.</sub>
